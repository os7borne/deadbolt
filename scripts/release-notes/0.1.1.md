- Deadbolt for Mac now updates itself: it checks about once an hour and installs new versions at a quiet moment. Turn it off or check by hand in Settings › General › Updates.
- Logins can be saved without a password, for sites that sign you in with an emailed link or code. Add a login from the Chrome toolbar button, starting from the page you are on.
- Chrome now offers to save sites that only email you a sign-in code.
- The Mac app trusts the Chrome Web Store version of the extension.
